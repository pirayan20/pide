01The same hierarchy, now persistent

Spaces group projects, with branch subtitles and open-tab counts. No Cmd+number navigation or shortcut badges. Selecting a project leaves the picker open.

02Two sidebars, independent controls

New Projects sidebar on the left; original Files / Source Control sidebar moved to the right. Each title-bar button collapses only its own sidebar. Both remain independently resizable in the proposed app layout.

03Activity belongs to the project

A small blue ring marks detected agent work; amber marks waiting. A Space keeps a summary even when folded. Waiting takes priority over working when a project has several agents. No agent means no badge.

One PIDE theme across both sidebars

Both panels inherit the active PIDE theme, including custom themes: surfaces, text, borders, selection, and semantic status colors. No separate sidebar theme setting. Dark / Light above previews both panels together.
